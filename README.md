# Email Extractor - Task Automation with Python

This project automates the repetitive task of extracting all email addresses from a text file and saving them into a new file.

## Features
- Extracts emails using Regex
- Removes duplicate emails
- Sorts emails alphabetically
- Saves output to a separate file

## Technologies Used
- Python
- `re` module for Regular Expression
- `os` module for file handling
